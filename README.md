# Atividade 01 - Sistemas Distribuídos e Redes de Comunicação
## Questão 07 da lista 01

No repositório tem 4 scripts, sendo dois clientes e dois servidores de um socket para UDP e TCP. Como informações adicionais, é importante destacar que para funcionar em uma rede local, por exemplo, é necessário abrir as portas no firewall (em máquinas Linux, o ufw, por exemplo). Além disso, checar os IP's de rede corretos para substituir nos scripts antes de executá-los.
